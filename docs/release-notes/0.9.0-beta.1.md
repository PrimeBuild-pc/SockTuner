# SockTuner 0.9.0-beta.1

## Automatic diagnosis and guided changes

- Start a complete diagnosis from the dashboard without identifying the problem yourself. Windows selects the interface used for the target; the results show observations, confidence, limitations and next steps.
- Review individual evidence-based actions before choosing changes. A successful run may correctly recommend no local change; there is no automatic universal gaming preset.
- Require characterised hardware, driver identity and matching property constraints before NIC writes, including validation in the elevated worker. Unverified adapters remain available for read-only diagnosis and compatibility reports.
- Compare before and after under matching conditions, with explicit outcomes for insufficient evidence, mixed results or no demonstrated difference. Existing supported changes retain their snapshot and rollback path.
- Include MSI/interrupt-affinity configuration and driver-store observations without automatically enabling privileged capture or bandwidth-load tests.
- Fix worker validation for dedicated setting backends, and prevent private traceroute hops from being treated as a declared router WAN address.
- Update TraceEvent to 4.0.0 and actions/setup-dotnet to 6.1.0.

## Validation

The implementation passed 981 tests including live inventory checks. A Windows 11 VM test applied a real temporary QoS policy, verified its value, rejected a stale plan and restored it successfully; NIC writes on the uncharacterised virtual adapter were refused. The VM was restored to its clean checkpoint. This does not qualify writes, restarts or performance gains on physical network adapters.

## Requirements, upgrade and limits

Windows 10 22H2 or supported Windows 11, x64. Extract the portable ZIP and run SockTuner.exe; no separate .NET installation is required.

This is a community beta, not a production or performance guarantee. Tuning is experimental and can interrupt the selected network link. Driver package cleanup remains separate and has no automatic undo. A short public-reference test cannot prove ISP responsibility or predict a particular game's performance.

Signing remains deferred. If `UNSIGNED-PREVIEW.txt` is included, the executable is unsigned; verify the published SHA-256 checksum before launching. Automatic installation of updates remains unavailable until both installed and new builds satisfy the publisher-signature checks.

Older context-free diagnostic reports require a new baseline for a reliable comparison. See [automatic diagnosis and its limits](../AUTOMATIC-DIAGNOSIS.md).
